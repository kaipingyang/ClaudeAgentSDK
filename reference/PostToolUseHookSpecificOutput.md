# Hook-specific output for PostToolUse hook

Hook-specific output for PostToolUse hook

## Usage

``` r
PostToolUseHookSpecificOutput(
  additional_context = NULL,
  updated_tool_output = NULL,
  updated_mcp_tool_output = NULL
)
```

## Arguments

- additional_context:

  Character or NULL.

- updated_tool_output:

  Any or NULL. Rewritten output for a regular tool.

- updated_mcp_tool_output:

  Any or NULL. Rewritten output for an MCP tool.

## Value

Object of class `PostToolUseHookSpecificOutput`.
